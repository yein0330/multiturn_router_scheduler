# 기존 로그 오프라인 분석 (v3 dev50, v4 단계 A·B)

- 새 추론은 없다. 모두 dev 데이터의 **사후 탐색**이다.
- 사용자가 제공한 분석 요약(E1–E5)을 이 폴더 스크립트로 독립적으로 다시 구현했다. 원본 스크립트는 이 서버에 없었다.
- 실행: `for f in e1 e2 e3 e3b e4 e5; do ../../.venv/bin/python $f.py; done` (`load.py`는 공통 로더). 결과 CSV는 이 폴더에 생성된다.

## 해석상 주의

- 요청 단위 사후 선택(E5)과 반복 시 B 규칙(E3b)은 **요청 독립과 이력 무관을 가정한 낙관적 진단**이다. E2와 v4 단계 B가 보여 주듯 이력은 결과를 바꾼다.
- E1의 "잃는 prefill"은 비용 모델 추정이다.
- 표본: v4 T1은 10세션 × 2문맥 = 요청 80개다.
