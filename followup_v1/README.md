## 3. 동일 prefix A/B 분기 진단 — 다음 호출 비교 (세션 반사실이 아님)

### 공통 방법

- 로그로 당시 텍스트 history를 재구성했다. 렌더링한 prompt의 해시가 로그와 30/30 일치했다.
- 각 모델이 그 시점까지 받은 prompt를 퇴거 이력을 반영해 다시 보내 캐시를 복원했다(준비 비용은 따로 기록).
- 같은 입력으로 A와 B를 각각 실행했다(greedy, 실제 출력 길이). 3회 반복하며 매번 다시 복원했고, A/B 순서는 섞었다.
- **측정 180행 모두 실제 적중 = 기대 적중이다(matched state).** 반복 간 출력은 모두 같았다(변동 0).
- 비용 예측은 동결된 적합식과 ĝ를 썼다. 실제 미래 길이는 쓰지 않았다.
