# 다음 결정: 후속 방법론의 실익과 남은 불확실성

근거는 [report.md](report.md)와 [cost_audit.md](cost_audit.md)에 있다. 이 문서는 판단 제안이며, 새 실험은 시작하지 않았다.

## 이번 결과로 정리된 것

1. **고정 전환 시점 조절은 공짜 개선이 아니다** [측정].
   - 늦게 전환할수록 품질과 지연이 함께 낮아지며, 항상 A와 항상 B를 잇는 선을 따른다.
   - B 수준 품질이 목표라면 다음이 가장 단순했다.
     - short: BBBBB 또는 ABBBB(지연 차 구간이 0 포함)
     - long: BBBBB(ABBBB는 2.4 s 느림)
2. **매 턴 라우팅(R)은 단순 고정 전환을 지배하지 못했다** [측정]. AABBB와 P4는 비슷한 자리에, ABBBB는 P4보다 품질이 높고 느린 자리에 있다.
3. **문맥 비용의 정체** [측정].
   - 다중 모델 사용의 추가 문맥 비용은 A의 최초 문맥 처리다(long에서 세션당 약 0.4 s).
   - B 복귀 재계산은 거의 발생하지 않았다.
   - 문맥 비용 자체는 작지만, 생성 절약이 작아지는 긴 문맥에서는 손익을 뒤집을 정도였다.
4. **늦은 전환의 회복 조건** [측정·탐색].
   - 오류가 드러나는 경우(verifier), 그리고 새 작업으로 넘어가는 경우에는 회복되었다.
   - 앞 코드의 오류가 이후 요청에 숨어 남는 연쇄(S4)에서는 회복되지 않았다.
   - 분기 진단에서도 단계 1 전환은 회복, 단계 3 전환은 (이전 오류가 있으면) 부분 회복 또는 실패였다.

## 후속 방법론을 만들 실익이 있는가

| 방향 | 실익 판단 | 이유 |
|---|---|---|
| 전환 시점 고정값 튜닝 | **낮음** | 품질–지연 선 위의 위치 선택일 뿐이다. 세션별 사후 최선 시점이 흩어져 있어 하나의 고정값이 대부분의 세션에서 최선이 아니다 |
| 다음 호출 단위의 캐시 비용 보정 | **낮음** | 결정이 바뀐 적이 없다(0/54 보류). 세션 비용 차이도 이 보정이 다루는 양과 다르다 |
| 세션 단위로 "A로 충분한가"를 미리 판단하는 신호 | **있을 수 있음[가설]** | 13/50 세션은 A만으로 품질 최대였다. 이를 미리 가려낼 수 있으면 항상 B 대비 지연을 크게 줄일 수 있다. 단 R은 이를 하지 못했다(턴 0에서 거의 항상 A, 첫 요청 10개 중 3개 오판) |
| 오류를 드러내는 신호를 이용한 늦은 전환 | **있을 수 있음[가설]** | S5에서 늦은 전환이 B에 근접했다. verifier 같은 신호가 없는 과제에는 적용할 수 없다 |
| 라우터 학습·보정 | 판단 보류 | 범위 밖이다. oracle 상한 분석(기존 로그, 추가 추론 없음)으로 먼저 상한을 확인해야 한다 |

## 남은 불확실성

- 모델 쌍 하나, 과제 생성기 하나, 50세션이다. 템플릿을 공유하므로 구간이 실제보다 좁을 수 있다.
- long에서 B 출력이 길어지는 현상(A 이력 뒤 +61토큰)의 원인을 확인하지 못했다. A 코드의 길이, 오류 형태, 문맥 길이 중 무엇인지 알 수 없다. 이것이 long 결론("BBBBB가 유리")의 상당 부분을 좌우한다.
- 분기 진단은 40점이고 S4 회복 실패는 소수 사례(3점)다. 반복 3회는 지연 측정용이며 품질 표본이 아니다.
- 마지막 단계 지표는 "누가 마지막 요청을 처리했는가"를 크게 반영한다. 최종 산출물만 중요한 과제로 일반화하려면 별도 과제가 필요하다.
- 동시성, 메모리 경쟁, 다른 엔진·하드웨어는 다루지 않았다.

## 사용자 결정이 필요한 선택지 (자동 진행하지 않음)

1. **oracle 상한 분석**(추가 추론 없음): 같은 세션의 고정 정책 6개 + P4/P6 결과로, 단계별 사후 최선 경로의 상한과 R의 손실을 분리한다.
2. **B 출력 길이 증가 원인 진단**(소규모 GPU): long ABBBB와 BBBBB의 단계 1 B 출력을 비교하고, 같은 이력에서 A 코드만 B 코드로 바꿔 넣는 분기를 만든다.
3. **세션 단위 "A 충분성" 신호 탐색**: 기존 로그의 첫 요청 특징(연산 종류, 요청 길이)과 AAAAA 충분 세션 13개의 관계를 본다. 탐색용이며 학습은 하지 않는다.
4. 위 결과를 보고 외부 과제(BFCL multi-turn 등)로 확장할지 결정한다.
